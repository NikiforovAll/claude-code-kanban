Swarm

Swarm reads the event log of one swarm and shows its progress, its workers, what they found and whose files they took. It reads the log through the store's export and never writes to the board; it deletes a run only when you confirm Delete in the run list. While the page is on screen, it checks the log once a second.

Swarm runs

Open a run, or delete one: Delete removes its folder with the recovery bundle, its board, its group and any leftover worktrees. A run with a worker that still runs is refused.
