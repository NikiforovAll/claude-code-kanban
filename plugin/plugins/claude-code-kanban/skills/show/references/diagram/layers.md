# Layers

For stacked levels: a tech stack, a cascade, a memory hierarchy, a context hierarchy. This is the type that suits the card best: it is tall by nature.

- 3 to 6 full-width bands of the same height (48 to 64 units), stacked with no gap and split by hairlines.
- Each band, left to right: an index tag in mono (`L3`, `APP`), the layer name in sans, a short note in muted mono at the right edge. On a 360 px card drop the note into a second line under the name.
- Fill: all `--color-bg` with hairlines, or alternate `--color-bg` and `--color-bg-subtle`. Pick one.
- Show direction once, outside the stack: a small arrow with a mono label (`requests ↓`).
- Accent on one layer: the bottleneck or the one under discussion.
- If the levels are not a hierarchy, it is an architecture or a swimlane.
