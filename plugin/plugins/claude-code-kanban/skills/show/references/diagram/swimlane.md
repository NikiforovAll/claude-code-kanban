# Swimlane

For a process that passes between people, teams or systems.

- On a card, lanes are columns, one per actor, at most 4, with time running down. Rows of lanes run sideways and do not fit.
- Each lane has a mono label at its top. Hairlines split the lanes.
- A step is a rect in the lane of the actor that does it, never across two lanes.
- Handoffs (lines that cross a lane border) are the edges that matter. Accent the one that adds the most delay or coupling.
- A lane with one step is fine; do not pad lanes to match.
- Order the steps so the flow goes mostly down; a line that zigzags between lanes means the order is wrong.
