The show card sits at the top right of the [embedded terminal](/claude-code-kanban/guides/embedded-terminal/) and keeps every post of the session in the terminal. To learn how Claude posts a card, see [Show cards](/claude-code-kanban/guides/show-cards/).

## The header

The header shows the title of the card on screen, the topic that Claude gave it, and its buttons:

| Button | What it does |
|---|---|
| <kbd>‹</kbd> <kbd>›</kbd> and the count | Go to the previous or next post. |
| Pane | Add the card's file as a pane of the session, next to Board. While the terminal covers the board, a toast says "Card added as a pane", with an Open button. |
| Dock | Put the card in a side panel beside the terminal. The terminal gets narrower, so long lines are easier to read and you see both at once. Drag the panel's left edge to change its width; double-click the edge to reset it. Collapse or close gives the terminal its full width back. Each terminal keeps its own choice. Off by default. |
| Collapse | Show only the header. Click it again to open the card. |
| Expand | Fill the terminal with the card. The card stops above the prompt, so you can still type to Claude. Not shown while the card is docked. |
| Remove | Delete the post on screen, after a confirm. <kbd>Shift</kbd>+click removes every post of the session. |
| Close | Hide the card until Claude posts again. To open it before that, click **show** in the terminal bar. |

Under the header, one tick stands for each post. Click a tick to go to that post. A dot on a tick means that Claude changed the post since you last saw it.

Drag the card's edge to resize it. The text grows with the card's width.

## Keys

Press <kbd>Ctrl+Alt+&#96;</kbd> to move focus between the terminal and the card. A closed or collapsed card opens first. You can also click the card's header or body. While the card has focus, it has an accent outline.

| Keys | Action |
| --- | --- |
| <kbd>[</kbd> or <kbd>]</kbd> | Previous or next post |
| <kbd>Alt+Enter</kbd> | Fill the terminal with the card, or go back to the card size |
| <kbd>Alt+Shift+Enter</kbd> | Dock the card beside the terminal, or go back to the overlay |
| <kbd>Esc</kbd> | Go back to the card size. If the card is not expanded, or it is docked, collapse it and focus the terminal. |
| <kbd>Alt+W</kbd> | Close the card until the next post, and focus the terminal |
| <kbd>Ctrl+D</kbd> | Remove the post on screen, after a confirm |
| <kbd>Ctrl++</kbd>, <kbd>Ctrl+-</kbd>, <kbd>Ctrl+0</kbd> | Card text size |

A text field inside an HTML card keeps these keys. See [Keyboard shortcuts](/claude-code-kanban/reference/keyboard-shortcuts/#show-card).

## Add-ons in the dock

An add-on is a web page that sits in the dock next to the card, such as a list of the files the session changed. It comes from a server you run. Ask Claude with `/addon` to build one or to add a URL, or add it yourself:

```bash
claude-code-kanban addon add "http://localhost:4100/?cwd={cwd}" --title Changes
```

The board fills `{sessionId}`, `{cwd}` and `{project}` for each session, so one add-on shows each session its own view. A `{name}` of your own takes its value from `--param name=value`, and `addon set <id> name=value` changes it for one session. An add-on is for this session; add `--global` to put it on the rail of every session. A global add-on can also start its own server: with `--run "<command>" --cwd <folder>`, the board runs the command the first time you open the add-on and its port does not answer, and stops it when the board stops.

To dock a web page that is already a pane, right-click its tab and click **Dock beside the terminal**. It stays a pane of the session.

A rail appears at the right edge of the terminal, with one icon for the card and one for each add-on. Click an icon to put it in the dock. Click the icon on screen to hide the dock and give the terminal its width back. <kbd>Alt+↑</kbd> and <kbd>Alt+↓</kbd> move to the previous or next icon while the terminal or the card has focus. When Claude posts a card while an add-on is open, a dot shows on the card's icon.

The add-on's header has these buttons:

| Button | What it does |
|---|---|
| Open | Open the page in a new browser tab. |
| Expand | Widen the add-on over the terminal, stopping above the prompt. Click it again to go back to the dock width. The board keeps this choice for every add-on. |
| Reload | Load the page again. |
| Remove | Take the add-on off the rail. A global add-on goes from every session, after a confirm. A docked pane goes back to being only a pane. |
| Close | Hide the dock. <kbd>Alt+W</kbd> does the same while the header has focus. |

When the session has no card, <kbd>Ctrl+Alt+&#96;</kbd> moves focus between the terminal and the add-on's header, and opens the first add-on when none is open. With the header focused, <kbd>Alt+↑</kbd> and <kbd>Alt+↓</kbd> move along the rail, <kbd>Alt+Enter</kbd> expands the add-on or takes it back to the dock width, and <kbd>Esc</kbd> takes it back, or focuses the terminal when it is not expanded.

A page hidden for a minute is unloaded and loads again when you open it. The page gets the board's theme colors. The board sends it nothing else: what it needs, such as the folder, goes in its URL.

## Open a card as a pane

The Pane button adds the card's file as a [pane](/claude-code-kanban/guides/panes/) of the posting session. The pane uses the same theme colors as the card. When Claude changes the file, the pane reloads. When you remove the post, its pane goes too.

Use a pane when you want the card next to the board, or when the card is too big for the terminal.

## Comment on a card

Select text in the card to add a [review comment](/claude-code-kanban/guides/review-comments/), as in a file preview. The comments list under the card body. Send them, and the session that posted the card gets them with the name of the card's file, so Claude knows which card you mean. Claude can then change the card, and the card shows the change.

## Answer from a card

A card can ask you a question with buttons or a form. Click a button, or fill the form and submit it, and the session gets your answer as its next prompt. A button sends at once. A form sends once, with all its fields. Only your click sends: a script in the card cannot answer for you. This works in any HTML preview, a pane and the file preview too.

## What the card keeps

- Each terminal opens the card the way you left it: collapsed, expanded or closed. This stays across a page reload.
- A new post opens a closed card.
- The posts belong to the session. `/clear` and a resume in the same terminal keep the card. After a board restart, the card comes back for each terminal.
- Removed posts are gone. A post of an existing file deletes only the post, not the file.
- Folds that you open in a call stack close again on the next render.

## Posts of an existing file

Claude can post a file that already exists: a markdown, HTML, text or image file, by its absolute path. An SVG file shows as a drawing. The card reads the file each time it loads, but does not watch it. To see a change, page away and back, or ask Claude to post it again.

A card that Claude writes for the post is different: the board watches that file, and the card follows each change.
