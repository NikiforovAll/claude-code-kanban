The board shows the tasks of a session. This page covers the panels and dialogs that show the rest: what Claude said, which tools it ran, its plan, and your own notes and files for the session.

## Session log

Press <kbd>Shift+L</kbd> or click the session log button above the board to open the Session Log panel on the right.

<Shot src="shots/01-board-session-log.webp" alt="The board with the Session Log panel open on the right, listing the latest tool calls and messages of the session" />

The panel loads the latest 15 messages. Scroll up to load older ones. Pinned messages and agents stay in a section at the top of the panel.

Click a message to open it in the message dialog. In the dialog:

- <kbd>↓</kbd> goes to the next message, and <kbd>↑</kbd> goes to the previous one. If the session waits for an answer, stepping past the last message shows the waiting prompt.
- The header buttons are View Agent (for a message from a subagent), Pin, Copy, Open in editor and fullscreen.
- <kbd>Ctrl++</kbd> and <kbd>Ctrl+-</kbd> make the text larger or smaller, from 0.7x to 2x. <kbd>Ctrl+0</kbd> resets it. The zoom works in every dialog that shows long text.

### Follow the latest message

Press <kbd>Shift+M</kbd> or click the clock button in the panel to open the latest message in follow mode. While follow mode is on, the dialog moves to each new message as Claude writes it. If the session waits for an answer, it shows the waiting prompt instead. Press <kbd>Shift+M</kbd> again to close the dialog. Stepping back with <kbd>↑</kbd> turns follow mode off. Pressing <kbd>↓</kbd> on the last message turns it on again.

For waiting prompts, see [Answer prompts from the board](/claude-code-kanban/guides/waiting-prompts/).

## Pinned messages

Click the bookmark icon in the message dialog or the agent dialog to pin that message or agent. Pinned items show at the top of the session log. The session card in the sidebar shows a badge with the count of pinned items. Click the badge to open the log.

Pins are stored per session in the browser's localStorage. A different browser or a private window does not see them.

## Session info

Press <kbd>I</kbd> or click the info icon on a session card to open the session info dialog. Each path row has a copy button, and most have an Open in editor button.

| Row | What it shows |
| --- | --- |
| Session | The session id. Open in editor opens the session transcript. |
| Continued from, Forked from | The earlier session, when this one continues or forks it. Click it to open that session. |
| Slug | The session slug. Open in editor opens the plan file. |
| Description | The session description, when it has one. |
| Project, Path, CWD | The project folder and the working directory. |
| Branch | The git branch. |
| Tasks Dir | The folder that holds the task files. |
| Scratchpad | The scratchpad folder that Claude Code uses for the session. |
| Shared Tasks | The shared task list, when the session uses one. |
| Team Config | The team config file, for team sessions. |

Below the rows the dialog shows context use, a plan card, linked documents, artifacts and team members, when the session has them.

The footer has three buttons:

- **Dismiss** hides the session from the Active list. <kbd>Ctrl+D</kbd> does the same. For a dismissed session the button reads **Restore**.
- **Tool Stats** opens the tool statistics.
- **Close** closes the dialog.

The header has a Sticky button. Inside [Claude Code Hub](/claude-code-kanban/guides/claude-code-hub/), it also has buttons that open the session in Cost, Marketplace and Memory.

<Shot themed="06-session-info" alt="Session info dialog with session, project, path and branch rows, context use and a plan card" />

### Context use

Context bars, total token counts and cost come from a mod in the plugin. It needs Claude Code 2.1.287 or later. Without it, the board shows only the rows that come from the transcript. See [Getting started](/claude-code-kanban/getting-started/).

The **Cache** row counts down until the prompt cache expires. The time starts at the last request of the main session. The time, the TTL (5 minutes or 1 hour), the model and the token counts of the last request come from the transcript, so the model name, these counts and this row show without the plugin too. After the time runs out, the next request writes the whole context to the cache again, and that costs more than a cache read. The row is green above 5 minutes, orange from 2 to 5 minutes and red under 2 minutes. Hover over it to see the clock time it expires and the estimated cost of that write. When the cache has expired, the row shows that cost, for example `expired · ~$1.08`. The estimate uses the list input price of the model and the cache-write rate of the TTL (1.25× for 5 minutes, 2× for 1 hour). It does not show for a model that cck has no price for. On a subscription plan the write costs usage limit, not money, but the estimate still shows how large it is.

## Tool stats

Click **Tool Stats** in the session info dialog. The Tool Statistics dialog shows totals for calls, unique tools, failed calls and rejected calls. A table lists each tool with its calls, successes, failures, rejections and impact. Impact is the share of all tool output, by character count. Click a column header to sort by it.

## Plan

Press <kbd>P</kbd> to open the plan of the selected session, or click the plan card in the session info dialog. The plan dialog has Open in editor, Copy and fullscreen buttons.

## Linked documents

Link files and web pages to a session to keep them one click away. The Linked documents section is in the session info dialog and in the zen mode panel. A session keeps up to 200 links. The newest link is first.

- Click **+** and type an absolute path, a `file://` URL, a path relative to the session working directory, or an `http://` or `https://` URL. Press <kbd>Enter</kbd> to link it. Other URL schemes are refused.
- Click a web URL to open it in a new browser tab. The row shows the URL without `https://`, with a ↗ mark, and a long URL is cut with an ellipsis. Hover the row to see the full URL.
- Click a Markdown, HTML, text or image file to open it in the Preview dialog. HTML renders in a sandboxed frame.
- A `scratchpad.json` file opens in the scratch viewer when it is installed.
- Other files open in your editor.
- Each row has a copy button (path or URL) and an unlink button.

The Preview dialog has a **Link to current session** toggle, an Open in editor button and a fullscreen button. Use the toggle to link or unlink the file you are reading. Select text in the file to comment on it, then send the comments to the session. See [Review comments](/claude-code-kanban/guides/review-comments/).

To link from a terminal or an agent, use `doc link <file|url>`. `doc preview` opens a file in the Preview dialog of open tabs and does not link it. `doc preview <url>` links the URL instead, and the tab on screen shows an **Open** button for 8 seconds. See the [CLI reference](/claude-code-kanban/reference/cli/).

## Panes

A pane is a live page or a file that shows as a tab next to Board. Use it for something you keep open while Claude works, such as a dev server, a report or a design. A session keeps up to 50 panes. The server stores them, so every browser shows the same panes.

<Shot src="shots/13-panes.webp" alt="The session view with three tabs, Board, Kanagawa preview and Plan, and the Plan tab on screen: a Markdown plan with goals, a token table and steps" />

- Click **+** at the end of the tab strip to add a pane. Type to search the session's linked documents, or paste a URL or a file path, then press <kbd>Enter</kbd>. A relative path starts from the session working directory. If the pane is already open, the board goes to its tab.
- Click **Open in a pane** in the Preview dialog to move the file you are reading into a pane.
- Click **Open in a pane** in the message dialog to keep a session log message in a pane. The pane shows that message, also after older messages leave the Session Log panel. Right-click its tab and select **Open in message dialog** to open it in the dialog again.
- Press <kbd>[</kbd> or <kbd>]</kbd> to go to the previous or next tab.
- Drag a tab onto another tab to move it. A line on that tab shows the side it lands on. The new order is stored with the panes, so every browser shows it.
- To close a pane, click × on its tab, middle-click the tab, or press <kbd>Alt+W</kbd>.
- Right-click a tab, or press <kbd>Shift+F10</kbd> or the <kbd>Menu</kbd> key for the tab that has focus, to copy its URL or path, open it in a new browser tab, rename it, reload it or close it. To rename, type the new title and press <kbd>Enter</kbd>, or press <kbd>Esc</kbd> to cancel. An empty title gives the pane its default title back. A file opens in the Preview dialog instead of a browser tab. The buttons at the right of the strip reload or open the pane on screen.
- The menu of the Board tab has **Delete completed tasks** and **Delete all tasks**. Each asks you to confirm, and the delete cannot be undone.

Claude adds panes with `pane add <url|file>`. The board does not switch to the new pane, so your view stays put. Any local server with a page works. `scratch ui <pad> --browser`, for example, prints a URL for the scratch viewer, which reloads itself when the pad changes.

#### File panes

A file pane shows HTML, Markdown, text, source code and images, like the Preview dialog. It reloads when the file changes and keeps its scroll position. A pane that is off screen reloads when you show it.

- Select text to comment on it, as in the preview.
- <kbd>Ctrl++</kbd> and <kbd>Ctrl+-</kbd> change the text size.
- Drag the edge of the page to change the reading width. Double-click the edge to reset it. The width applies to every file pane.
- In an HTML page, web links open in a new browser tab. The board keys for the sidebar, tabs and splits still work there.

#### URL panes

A URL pane shows the live page. Some sites refuse to load in a frame (`X-Frame-Options` or CSP `frame-ancestors`), and their pane shows an **Open in new tab** card instead. A pane cannot show the board or the hub.

The page runs on another origin, so it keeps every key while it has focus. Click outside the page before you use a board or hub shortcut such as <kbd>Ctrl+`</kbd> or <kbd>Ctrl++</kbd>.

### Split view

Show two tabs side by side, for example the board next to a report Claude is writing.

<Shot src="shots/13b-split-view.webp" alt="The session view split in two: the board with pending, in progress and completed tasks on the left, and an HTML pane with a Kanagawa theme preview on the right" />

- Press <kbd>|</kbd> or click the split button at the right of the tab strip. The tab on screen and the tab before it show side by side. Press <kbd>|</kbd> again to end the split.
- Drag a tab onto a side to show it there.
- Drag the divider to resize the sides, or to an edge to end the split. Double-click it to reset.
- <kbd>&#123;</kbd> and <kbd>&#125;</kbd> move focus to the left or right side. <kbd>Alt+[</kbd> and <kbd>Alt+]</kbd> change the tab in the focused side.
- <kbd>[</kbd> and <kbd>]</kbd> treat a split as one tab.

You can keep several splits. Click a tab outside a split to show it alone. The split comes back when you go to one of its tabs. Splits last until you close the browser tab, and the divider position is the same for all of them.

With the board in a split, the session log opens inside the board's side, and the agent log starts collapsed. A narrow board side packs its three columns tighter. Below about 476 px, it scrolls sideways.

## Scratchpad

Press <kbd>N</kbd> to open the scratchpad of the selected session. In the sidebar, <kbd>N</kbd> opens the scratchpad of the item under the cursor. Project headers and group headers have a scratchpad button for a project note or a group note.

The note saves itself 500 ms after you stop typing. It is stored in the browser's localStorage. A session card shows a scratchpad badge when its note has text.

This note is different from the Scratchpad row in session info. That row is the folder Claude Code uses for temporary files.

## Storage manager

Pins, links, notes and groups live in your browser. Press <kbd>Shift+S</kbd> to open the Storage Manager and review pins, notes and links. It has three tabs: Sessions, Scratchpads and Linked Docs. **Clean Orphaned** removes the data of sessions that no longer exist. The button shows how many items it will remove.

## Session picker

Press <kbd>Ctrl+Shift+P</kbd> to open the session picker and jump to a session.

- <kbd>↓</kbd> or <kbd>Ctrl+N</kbd> moves down, and <kbd>↑</kbd> or <kbd>Ctrl+P</kbd> moves up.
- <kbd>Enter</kbd> opens the session.
- <kbd>Ctrl+Space</kbd> peeks at the recent messages of the selected session.
- <kbd>Esc</kbd> closes the picker.

The picker lists the sessions the sidebar shows. To find a session outside the current filter, type 3 or more characters of its name or its session id. In a session id, dashes are optional. Matches from all sessions show below the sidebar matches, newest first, with the full project path. Up to 20 are shown.

## Choose the editor

Every Open in editor button runs the command in the `EDITOR` environment variable of the server. The default is `code`. Set it before you start the server:

```bash
EDITOR="code -w" claude-code-kanban
```

For all keys, see [Keyboard shortcuts](/claude-code-kanban/reference/keyboard-shortcuts/).
