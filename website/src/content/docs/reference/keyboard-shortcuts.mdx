Press <kbd>?</kbd> (or <kbd>Shift+/</kbd>) to open the **Keyboard Shortcuts** help. Press <kbd>?</kbd> or <kbd>Esc</kbd> to close it. The help does not open while the cursor is in a text field, a text area or a select.

The help has four tabs: Board, Session, Terminal and Hub. This page lists their groups in the same order.

<Shot themed="12-shortcuts" alt="The Keyboard Shortcuts help with its Board, Session, Terminal and Hub tabs" />

Plain letter keys work only when you press no modifier. For example, <kbd>I</kbd> opens session info, and <kbd>Ctrl+I</kbd> does nothing in Claude Code Kanban. Letter keys do nothing while you type in a field.

## Navigate

| Keys | Action |
| --- | --- |
| <kbd>↓</kbd> | Next item |
| <kbd>↑</kbd> | Previous item |
| <kbd>←</kbd> | Left column, or collapse a group in the sidebar |
| <kbd>→</kbd> | Right column, or expand a group in the sidebar |
| <kbd>Tab</kbd> | Move focus between the sidebar and the board |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Open the selected item |

When the [embedded terminal](/claude-code-kanban/guides/embedded-terminal/) replaces the board, <kbd>Tab</kbd> moves focus between the sidebar and the terminal. If the board has no task cards, <kbd>Tab</kbd> from the sidebar does nothing.

## Board

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Open or close the task detail panel for the selected card |
| <kbd>D</kbd> | Delete the selected task, after you confirm |
| <kbd>N</kbd> | Open or close the scratchpad. In the sidebar, open the scratchpad of the item under the cursor. |
| <kbd>Ctrl+E</kbd> | In a session scratchpad, set the session's emoji |
| <kbd>R</kbd> | Refresh sessions, the open session's tasks and the rate limits. A "Data refreshed" message shows when it is done. |
| <kbd>Esc</kbd> | Close the next open item, in this order |

<kbd>Esc</kbd> on the board closes one item each time you press it:

1. The task detail panel.
2. The agent log in the session log panel.
3. The session log panel.
4. If nothing is open, it clears the task selection.

In the sidebar, <kbd>Esc</kbd> removes the keyboard cursor.

## Tabs

| Keys | Action |
| --- | --- |
| <kbd>[</kbd> or <kbd>]</kbd> | Go to the previous or next tab of the session view: Board, then the session's panes. A split counts as one tab. It does nothing while the terminal is on. |
| <kbd>&#124;</kbd> | Split the tab on screen with the tab before it, or end the split. See [Split view](/claude-code-kanban/guides/panes/#split-view). |
| <kbd>&#123;</kbd> or <kbd>&#125;</kbd> | Move focus to the left or right side of a split |
| <kbd>Alt+[</kbd> or <kbd>Alt+]</kbd> | Change the tab in the side of a split that has focus |
| <kbd>Alt+W</kbd> | Close the pane that has focus. It does nothing on Board. |
| <kbd>Shift+F10</kbd> | Open the menu of the tab that has focus. The <kbd>Menu</kbd> key also works. In the sidebar, the item under the cursor gets its menu instead. |

## View

| Keys | Action |
| --- | --- |
| <kbd>&#92;</kbd> | Show or hide the sidebar |
| <kbd>T</kbd> | Switch between light and dark theme |
| <kbd>Shift+S</kbd> | Open the storage manager |
| <kbd>Ctrl+Shift+Z</kbd> | Turn zen mode on or off (current session only). It works when the terminal has focus. In a text field it stays redo. <kbd>Shift+Z</kbd> also works outside the terminal. |
| <kbd>Ctrl+Shift+K</kbd> | Show or hide Kanbot, the board assistant. Show puts focus in Kanbot's terminal, and hide gives focus back to where it was. It works from the board terminal and from inside Kanbot. It does nothing when the terminal is off. |
| <kbd>Ctrl++</kbd> | Larger text in the open window |
| <kbd>Ctrl+-</kbd> | Smaller text in the open window |
| <kbd>Ctrl+0</kbd> | Reset the text size in the open window |
| <kbd>?</kbd> | Show the help |

The text size keys work only when a window with readable content is open, such as a message, a plan or a preview, or when a pane is on screen. They scale HTML pages too. They also accept <kbd>Ctrl+=</kbd>, <kbd>Ctrl+_</kbd> and the numeric keypad keys, and they work with the cursor in a field. On macOS, <kbd>Cmd</kbd> also works. With no such window open, the browser zooms the page as usual. When the terminal has focus, they change the terminal text size instead (see [Terminal](#terminal)).

## Session

These keys act on the session under the sidebar cursor, or on the open session.

| Keys | Action |
| --- | --- |
| <kbd>P</kbd> | Open the session plan |
| <kbd>Ctrl+Shift+P</kbd> | Open or close the session picker. It works when the terminal has focus. |
| <kbd>Shift+P</kbd> | Open the project picker of this board |
| <kbd>I</kbd> | Open session info |
| <kbd>.</kbd> | Pin or unpin the session |
| <kbd>&gt;</kbd> | Make the session sticky, or remove sticky |
| <kbd>Shift+F10</kbd> | In the sidebar, open the menu of the item under the cursor, to move it to a group or fork a session. The <kbd>Menu</kbd> key also works. |
| <kbd>Ctrl+D</kbd> | Dismiss the session |
| <kbd>Shift+L</kbd> | Show or hide the session log |
| <kbd>Shift+M</kbd> | Open the last message in follow mode. If a waiting prompt is fresh, open that prompt. If the message detail is open, close it. |

### Message detail

These keys work in the message detail window. See [Session log and details](/claude-code-kanban/guides/session-details/).

| Keys | Action |
| --- | --- |
| <kbd>↓</kbd> | Next message. After the last message, show the waiting prompt if there is one. |
| <kbd>↑</kbd> | Previous message |
| <kbd>Ctrl+Enter</kbd> | Allow the waiting permission prompt, or approve the waiting plan. With review comments to send, send them. |

<kbd>Ctrl+Enter</kbd> works only when the waiting prompt is on screen and you can answer it from the board. It does not answer questions. On macOS, <kbd>Cmd+Enter</kbd> also works. See [Answer prompts from the board](/claude-code-kanban/guides/waiting-prompts/).

## Sessions

| Keys | Action |
| --- | --- |
| <kbd>Ctrl+Alt+N</kbd> | Start a new session |
| <kbd>Ctrl+Alt+R</kbd> | Resume a session with the `claude --resume` picker |
| <kbd>Ctrl+Alt+S</kbd> | Swap to the previous session |
| <kbd>Shift+C</kbd> | Copy the session id |
| <kbd>Ctrl+Shift+C</kbd> | Copy `SendMessage(<name>)`, where the name is the address other sessions use with SendMessage (running sessions only) |

If no session is selected, the copy keys show a "No session selected" message.

On macOS the three <kbd>Ctrl+Alt</kbd> keys are <kbd>⌃⌥N</kbd>, <kbd>⌃⌥R</kbd> and <kbd>⌃⌥S</kbd>.

<kbd>Ctrl+Alt+N</kbd> and <kbd>Ctrl+Alt+R</kbd> work only when the terminal is available. <kbd>Ctrl+Alt+S</kbd> switches between the last two sessions you opened. If the terminal has focus, it keeps focus after the swap. Inside Claude Code Hub, Claude Code Kanban keeps these three keys and does not send them to the hub.

## Terminal

These keys work anywhere on the page, also from inside the terminal. See [Embedded terminal](/claude-code-kanban/guides/embedded-terminal/).

| Keys | Action |
| --- | --- |
| <kbd>Ctrl+&#96;</kbd> | Show or hide the terminal |
| <kbd>Alt+&#96;</kbd> | Move focus between the terminal and the page. If the terminal is hidden, show it. |
| <kbd>Ctrl+Alt+&#96;</kbd> | Move focus between the terminal and the show card. A closed or collapsed card opens first. |
| <kbd>Alt+Shift+&#96;</kbd> | End the terminal session and close it. This works in the session view whenever the session has a running terminal, also when the terminal is hidden. |
| <kbd>Ctrl+Shift+&#96;</kbd> | Open the Terminals manager |

These keys use the physical key left of <kbd>1</kbd>. They do nothing when you also hold <kbd>Cmd</kbd>.

Inside the terminal:

- <kbd>Ctrl+C</kbd> copies when text is selected. With no selection, it goes to the terminal as usual.
- <kbd>Ctrl+Shift+C</kbd> always copies the selection.
- <kbd>Ctrl+V</kbd> pastes from the clipboard.
- <kbd>R</kbd> reconnects when the loading screen says "Slow to connect". This shows when the connection has not opened after 1.5 s. At other times, <kbd>R</kbd> goes to the terminal as usual.
- <kbd>Ctrl++</kbd> and <kbd>Ctrl+-</kbd> make the terminal text larger or smaller, from 8 px to 32 px. <kbd>Ctrl+0</kbd> resets it. <kbd>Ctrl+_</kbd> still goes to Claude Code as undo.

### Show card

These keys work while the show card above the terminal has focus. Press <kbd>Ctrl+Alt+&#96;</kbd>, or click the card's header or body, to focus it.

| Keys | Action |
| --- | --- |
| <kbd>[</kbd> or <kbd>]</kbd> | Previous or next post |
| <kbd>Alt+Enter</kbd> | Fill the terminal with the card, or go back to the card size |
| <kbd>Esc</kbd> | Go back to the card size. If the card is not expanded, collapse it to its header and focus the terminal. |
| <kbd>Alt+W</kbd> | Close the card until the next post, and focus the terminal |
| <kbd>Ctrl+D</kbd> | Remove the post on screen, after a confirm |
| <kbd>Ctrl++</kbd>, <kbd>Ctrl+-</kbd>, <kbd>Ctrl+0</kbd> | Card text size |

A text field inside an HTML card keeps these keys.

## Hub

These keys work when Claude Code Kanban runs inside [Claude Code Hub](/claude-code-kanban/guides/claude-code-hub/).

The Hub tab of the help shows only the keys that work. Outside the hub, that is the app links set with `--marketplace-url`, `--cost-url` or `--memory-url`. With none of them, the tab is hidden.

| Keys | Action |
| --- | --- |
| <kbd>M</kbd> | Go to Marketplace, scoped to the session's project |
| <kbd>$</kbd> | Go to Cost, on the session detail view |
| <kbd>Ctrl+M</kbd> | Go to Memory, scoped to the session's project |
| <kbd>Ctrl+Alt+←</kbd> or <kbd>Ctrl+Alt+→</kbd> | Previous or next hub app |
| <kbd>Alt+1</kbd> to <kbd>Alt+9</kbd> | Go to a hub app by its number |
| <kbd>Ctrl+Alt+P</kbd> | Open the project picker |
| <kbd>Ctrl+Alt+W</kbd> | Open the config dir picker |
| <kbd>Ctrl+Alt+A</kbd> | Open the app launcher |

On macOS the keys are the same, written <kbd>⌃⌥←</kbd>, <kbd>⌃⌥→</kbd>, <kbd>⌃⌥P</kbd>, <kbd>⌃⌥W</kbd> and <kbd>⌃⌥A</kbd>, and the hub app numbers use <kbd>⌃⌥1</kbd> to <kbd>⌃⌥9</kbd> instead of bare <kbd>Alt</kbd>.

These are the hub's default keys. When you [change the hub keys](https://nikiforovall.blog/claude-code-hub/reference/shortcuts/#change-the-keys), the help shows your keys and hides a row that has no key. <kbd>M</kbd>, <kbd>$</kbd> and <kbd>Ctrl+M</kbd> belong to Claude Code Kanban and do not change.

## Dialog keys

### New session dialog

| Keys | Action |
| --- | --- |
| <kbd>↓</kbd> or <kbd>↑</kbd> | Move in the folder list |
| <kbd>Enter</kbd> | Pick the highlighted folder, or start the session |
| <kbd>Ctrl+Enter</kbd> | Start the session from the prompt field (<kbd>Cmd+Enter</kbd> on macOS) |
| <kbd>Esc</kbd> | Close the folder list. Press again to close the dialog. |

### Session picker

| Keys | Action |
| --- | --- |
| <kbd>↓</kbd> or <kbd>Ctrl+N</kbd> | Next session |
| <kbd>↑</kbd> or <kbd>Ctrl+P</kbd> | Previous session |
| <kbd>Enter</kbd> | Open the session |
| <kbd>Ctrl+Space</kbd> | Turn peeking on or off |
| <kbd>Esc</kbd> | Close the picker |

### Terminal prompt buttons

The terminal shows buttons when a session runs in another terminal, when Claude exits, or when the connection drops.

| Keys | Action |
| --- | --- |
| <kbd>←</kbd> or <kbd>↑</kbd> | Previous button |
| <kbd>→</kbd> or <kbd>↓</kbd> | Next button |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Press the button |
| <kbd>Esc</kbd> | Show or hide the terminal |

## Keys while a window is open

When a window is open, most shortcuts stop. These keys go through:

- <kbd>Esc</kbd> closes the top window only. If the scratchpad is open, it closes first.
- <kbd>?</kbd> closes the help.
- <kbd>Shift+M</kbd> closes the message detail.
- The [message detail keys](#message-detail) work in the message detail.

The terminal keys, the Sessions keys, <kbd>Ctrl+Shift+P</kbd>, <kbd>Ctrl+Shift+Z</kbd>, <kbd>Ctrl+Shift+K</kbd> and the text size keys also work while a window is open. Inside Claude Code Hub, <kbd>Ctrl+Alt+←</kbd>, <kbd>Ctrl+Alt+→</kbd>, <kbd>Alt+1</kbd> to <kbd>Alt+9</kbd> (<kbd>⌃⌥1</kbd> to <kbd>⌃⌥9</kbd> on macOS), <kbd>Ctrl+Alt+P</kbd>, <kbd>Ctrl+Alt+W</kbd> and <kbd>Ctrl+Alt+A</kbd> also work.
